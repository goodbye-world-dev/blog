**Goodbye World** is a learning-in-public blog about AI agent orchestration — the messy, fast-moving space of orchestrators, sandboxes, protocols, and the tools that glue them together.

I'm Paweł Kamiński. I'm using this site as a public lab notebook: each post documents something I tried, what worked, what didn't, and what question opened up next.

## What you'll find here

- A numbered series on agent orchestration (mental models → tooling landscape → POCs → observability)
- Side-by-side framework comparisons with working code
- Honest write-ups of POCs, including the parts that broke
- Companion code in [agenticflow-examples](https://github.com/) (link will work once the repo is up)

## How to follow along

The site has an [RSS feed](/rss.xml) — that's the only follow mechanism for now. A newsletter and comments will come later.
